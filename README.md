# discord-badges
Follow the instructions below:  
1. Make sure the Discord client is the desktop app, not the browser 
2. Press Ctrl + Shift + I (Windows) or Cmd + Option + I (Mac) to open DevTools
3. Go to the Console tab.
4. If you cant Paste type "allow pasting" or copy and paste it
5. Paste the code from badges.js and press Enter
